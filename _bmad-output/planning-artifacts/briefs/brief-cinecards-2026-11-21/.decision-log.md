# Decision log — CineCards

- 2026-11-21 — Projet créé. Méthode : BMAD v6.12.4 + module Game Dev Studio (gds). Plateforme : navigateur (web).
- 2026-11-21 — Langues : code en anglais ; conversation et documents de planification en français.
- 2026-11-21 — Concept initial (utilisateur) : jeu de cartes à collectionner type Pokémon TCG, thème cinéma, combats entre joueurs, mode en ligne.
- 2026-11-22 — Reprise du brief après brainstorm. Source : `_bmad-output/brainstorming-session-2026-11-21.md` (66 idées, statut complete).
- 2026-11-22 — Le jeu existe en version papier (set Matrix, 18 cartes de référence dans `docs/reference/paper-cards-matrix.jpg`) : le projet est une adaptation numérique en ligne.
- 2026-11-22 — Règles confirmées : deck commun de 200 cartes uniques ; main de départ 7 ; pioche 1/tour ; revenu = numéro du tour, épargne, stock max 10 ; 10 cartes max sur la table ; mal d'invocation ; 1 attaque/carte/tour sauf exception ; riposte ; 700 PV joueur protégés par les personnages ; 4 raretés (commune, rare, épique, légendaire) + sorts + terrains.
- 2026-11-22 — Périmètre : pas de méta-jeu ; duel 1v1 ; parties privées (lien/code/amis) ; comptes e-mail/Google ; émotes prédéfinies ; chrono par tour ; 1-2 min de reconnexion sinon défaite. Écartés : IA, matchmaking public, spectateurs, 3-4 joueurs, 2v2, replays, tournois.
- 2026-11-22 — Choix utilisateur : une question à la fois.
- 2026-11-22 — Enjeu : projet perso, jeu entre amis, sans diffusion publique. Les visuels de films/acteurs réels sont conservés (usage privé). Brief dimensionné en conséquence (pas de rigueur éditeur/marché).
- 2026-11-22 — Voie rapide choisie. Brief rédigé avec balises [HYPOTHÈSE] ; addendum créé (anatomie des cartes, vocabulaire d'effets, alternatives écartées). Polish passes bmad-editorial-review-* non installées dans cette version : passe éditoriale faite manuellement.
- 2026-11-22 — Équipe : Claude fait tout (design formalisé, architecture, code, saisie des cartes, tests) ; Root fournit les cartes papier et images, arbitre les règles, valide et teste.
- 2026-11-22 — Contenu : environ 500 cartes (et non 200), fournies plus tard par Root. En attendant, travail sur la base du set Matrix (18 cartes de l'image).
- 2026-11-22 — Contenu : cartes tirées de films des années 1990 et 2000.
